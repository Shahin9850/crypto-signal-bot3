# Crypto Signal Bot (POC + Structure + FVG, Multi-Timeframe)

ربات تلگرامی که با استراتژی چندتایم‌فریمی زیر روی کریپتو سیگنال می‌ده:

- **تحلیل بایاس روی تایم‌فریم ۴ ساعته**: آخرین شکست ساختار (BOS) رو پیدا می‌کنه
  و فقط وقتی معتبرش می‌دونه که POC کندل شکست هم‌جهت شکست باشه (POC بالا برای
  شکست صعودی، POC پایین برای شکست نزولی). ناحیه FVG ایجادشده به‌عنوان POI
  (نقطه مورد علاقه) برای پولبک ثبت می‌شه.
- **ورود روی تایم‌فریم ۱۵ دقیقه**: وقتی قیمت به POI رسید، دنبال CHoCH مینور
  هم‌جهت بایاس می‌گرده، دوباره POC کندل CHoCH رو چک می‌کنه، و ورود رو روی لبه
  FVG تایم پایین (یا لبه POI) قرار می‌ده. استاپ پشت آخرین سوینگ، تارگت با
  نسبت ریسک‌به‌ریوارد ثابت (پیش‌فرض ۱:۲، قابل تنظیم).
- سیگنال‌ها تو دیتابیس SQLite ذخیره می‌شن، هر ۶۰ ثانیه (قابل تنظیم) قیمت
  لحظه‌ای چک می‌شه تا TP یا SL خورده باشه، بعد گزارش تو تلگرام ارسال می‌شه.
- هر ۱۰ سیگنال (قابل تنظیم با `BATCH_SIZE`) یه گزارش خودکار از تعداد
  تیک‌پرافیت/استاپ اون دسته ارسال می‌شه.
- فرستادن کلمه **"وضعیت"** (یا دستور `/status`) در هر لحظه، آمار کامل
  همه‌ی سیگنال‌های تاریخچه (تعداد تیک‌پرافیت، استاپ، باز، وین‌ریت) رو برمی‌گردونه.

## ⚠️ محدودیت مهم درباره POC

POC واقعی (فوت‌پرینت/آردرفلو) نیاز به دیتای تیک‌به‌تیک بید/اسک داره که اکثر
API های رایگان صرافی‌ها (از جمله Binance) ندارنش. این پروژه POC رو **تقریبی**
از روی کندل‌های ۱ دقیقه‌ای داخل هر کندل بزرگ‌تر می‌سازه (پروفایل حجمی بر
اساس قیمت میانگین هر کندل ۱ دقیقه‌ای). این تقریب برای تشخیص "حجم بیشتر
سمت بالا/پایین/وسط کندل بوده" کاربردی‌ست ولی دقتش با فوت‌پرینت واقعی (مثل
DTORDERFLOWBARS روی TradingView) یکسان نیست.

## نصب

```bash
git clone <this-repo-url>
cd crypto-signal-bot
python -m venv venv
source venv/bin/activate      # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

فایل `.env` رو ویرایش کن:

- `TELEGRAM_BOT_TOKEN`: توکن ربات از [@BotFather](https://t.me/BotFather)
- `TELEGRAM_CHAT_ID`: آیدی چت/کاربر/گروهی که سیگنال‌ها اونجا ارسال بشه
  (می‌تونی با ارسال یک پیام به ربات و چک‌کردن `getUpdates` پیداش کنی)
- `EXCHANGE_ID`: هر صرافی پشتیبانی‌شده توسط ccxt (پیش‌فرض `binance`)
- بقیه پارامترها (تایم‌فریم‌ها، ریسک‌به‌ریوارد) قابل تنظیم‌ان

### انتخاب نماد: ثابت یا کل بازار

دو حالت داره که با `SYMBOL_MODE` تعیین می‌شه:

- **`SYMBOL_MODE=static`** — فقط همون نمادهایی که تو `SYMBOLS` می‌نویسی
  (مثلاً `BTC/USDT,ETH/USDT`) رصد می‌شن.
- **`SYMBOL_MODE=auto`** (پیش‌فرض تنظیم‌شده) — ربات خودش هر
  `SYMBOL_REFRESH_SECONDS` ثانیه (پیش‌فرض ۹۰۰ = ۱۵ دقیقه) لیست همه‌ی
  جفت‌ارزهای فعال بازار رو از صرافی می‌گیره، بر اساس حجم معاملات ۲۴ ساعته
  مرتب می‌کنه، توکن‌های اهرمی/مصنوعی (UP/DOWN/BULL/BEAR/...) رو حذف می‌کنه
  و **۳۰ تای پرحجم‌تر** (`AUTO_TOP_N=30`) رو برای اسکن نگه می‌داره. این یعنی
  عملاً کل بازار رصد می‌شه، ولی فقط روی نمادهایی که واقعاً نقدشونده و
  معنادارن تمرکز می‌کنه — چون اسکن واقعی همه‌ی ۵۰۰+ نماد بازار همزمان به
  Rate Limit صرافی می‌خوره.
- `SCAN_INTERVAL_SECONDS=900` یعنی هر ۱۵ دقیقه یک دور اسکن کامل روی لیست
  نمادهای فعلی انجام می‌شه.

با فرستادن `/start` به ربات می‌تونی ببینی الان تو چه حالتی‌ه و چند نماد
داره رصد می‌کنه.

## ساختار پروژه

```
config.py            تنظیمات از .env
database.py           لایه SQLite برای ذخیره سیگنال‌ها
data_fetcher.py        دریافت کندل از صرافی با ccxt
symbol_universe.py      کشف خودکار نمادهای پرحجم بازار (SYMBOL_MODE=auto)
poc.py                 تقریب Point of Control
structure.py           تشخیص سوینگ/BOS/CHoCH
fvg.py                  تشخیص Fair Value Gap
strategy.py             ترکیب همه اجزا -> تولید سیگنال نهایی
signal_manager.py        اسکن، ارسال، مانیتور TP/SL، گزارش‌ها
bot.py                   اجرای ربات تلگرام + زمان‌بند
```

## هشدار

این پروژه صرفاً یک ابزار تحلیلی/آموزشی‌ست، نه توصیه مالی. قبل از استفاده با
پول واقعی، حتماً استراتژی رو روی دیتای تاریخی بک‌تست کن و منطق POC/ساختار
رو با نیاز خودت تنظیم و اعتبارسنجی کن. مسئولیت هرگونه معامله بر عهده خودته.
